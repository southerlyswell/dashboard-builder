# Spec: AI Personality System — soul.md + rules.md

**Branch:** `dev/ai-soul-tools`
**Status:** Spec — not built
**Created:** 2026-07-06

## Problem

The AI's entire personality, tone, and behavioral rules are hardcoded as a PHP string inside `DashboardAIService::buildSystemPrompt()`. To change ANYTHING about how the AI behaves:

1. Read the PHP file (you or me)
2. Find the right string in a 50-line concatenation chain
3. Edit it
4. Hope you didn't break the string escaping
5. Reload

You can't tune the AI from within the app. You can't experiment. You can't version just the AI's personality separately from the code.

## Solution

Extract the static parts of the system prompt into two editable `.md` files:

| File | Purpose | Example content |
|---|---|---|
| `storage/ai/soul.md` | Role, personality, tone, identity | "You are a knowledgeable AI dashboard assistant. You help users understand their data..." |
| `storage/ai/rules.md` | Dashboard structure, card types, grid layout, constraints, integrity rules | "DASHBOARD STRUCTURE: Row 1: Title (w=4, h=2). Row 2: 3-4 KPIs (w=1 each, h=3)..." |

## How it works

`buildSystemPrompt()` reads both files at runtime:

```php
private function buildSystemPrompt(?Client $client): string
{
    $soul = file_exists(storage_path('ai/soul.md'))
        ? file_get_contents(storage_path('ai/soul.md'))
        : $this->defaultSoul();

    $rules = file_exists(storage_path('ai/rules.md'))
        ? file_get_contents(storage_path('ai/rules.md'))
        : $this->defaultRules();

    $prompt = $soul . "\n\n" . $rules . "\n\n";

    // Dynamic parts still generated by PHP:
    if ($client && $client->schema_snapshot) {
        $prompt .= "Current client database: {$client->name}\n";
        // ... table/column listing
    }

    return $prompt;
}
```

## What moves where

| Current `buildSystemPrompt()` content | Moves to |
|---|---|
| Dual-mode description (conversation vs dashboard) | `soul.md` |
| How to choose mode, conversation rules | `soul.md` |
| Usability guidance, tone | `soul.md` |
| Dashboard structure (card rows, column layout) | `rules.md` |
| KPI rules, chart type matching, grid dimensions | `rules.md` |
| Dashboard integrity rules (add to bottom, don't reposition) | `rules.md` |
| JSON format example | `rules.md` |
| Client database schema listing | **Stays in PHP** (dynamic) |
| `$client->name`, table/column data | **Stays in PHP** (dynamic) |

## Fallback

If either file is deleted or unreadable, PHP generates sensible defaults from inline strings. The system never breaks — it just reverts to built-in defaults.

## Versioning

`soul.md` and `rules.md` live in `storage/ai/` which is outside the public web root. They are tracked by git. Changes to these files create meaningful commit history:

```
git log -- storage/ai/soul.md
abc1234 — tune: make AI more direct in questions
def5678 — feat: add South African context awareness
```

## User workflows

### Tune the AI manually
1. Open `storage/ai/soul.md` in any text editor
2. Change "You are a knowledgeable assistant" to "You are a blunt, no-nonsense assistant"
3. Save
4. Next chat message uses the new tone — no PHP change, no reload

### Tune the AI from within the app (Phase 2)
Once file tools are built (spec #2), you can say in chat:
- "show me the soul.md"
- "change the AI to be more direct and less apologetic"
- "show me the rules file"

## Deliverables

1. New file: `storage/ai/soul.md` — populated with current system prompt personality sections
2. New file: `storage/ai/rules.md` — populated with current system prompt rules sections
3. Modified: `app/Services/DashboardAIService.php` — `buildSystemPrompt()` reads from files
4. Modified: `app/Services/DashboardAIService.php` — inline fallback defaults remain

## Risks

| Risk | Mitigation |
|---|---|
| File not found (deleted, moved) | Inline fallback generation from PHP constants |
| Large files (>100KB) | Truncate to 50KB with warning log |
| Encoding issues (BOM, special chars) | `mb_convert_encoding` to UTF-8 on read |
| User edits break the prompt | Git versioning — `git checkout -- storage/ai/soul.md` to revert |
